# Werke, Besetzungen und Mitglieder verwalten

Diese Anleitung beschreibt den aktuellen Quellstand. Die veröffentlichte
Vorschau **0.1.0-preview.1** enthält diese neuen Verwaltungsfunktionen noch nicht.

1. Öffnen Sie **Instrumente und Stimmen**. Legen Sie eine Instrumentenvariante
   mit Stimmung und Notation an. Gleich benannte Instrumente mit anderer Stimmung
   oder anderem Schlüssel sind unterschiedliche Varianten.
2. Fügen Sie die tatsächlich spielbaren Stimmen hinzu, beispielsweise **1**, **2**
   oder **Solo**. Verwenden Sie bei Zuordnungen immer die Auswahllisten.
3. Unter **Mitglieder** legen Sie Personen mit genau einer **Stammstimme** an.
   Gleiche Namen sind erlaubt. Kennung und optionale Mitgliedsnummer helfen bei
   der Unterscheidung. Gäste werden später direkt im Projekt verwaltet.
4. Öffnen Sie **Werke und Arrangements**. Legen Sie das Werk an und fügen Sie
   seine Arrangements hinzu. Arrangeur und Ausgabe unterscheiden Bearbeitungen;
   auch gleiche Titel bleiben eigenständige Werke.
5. Tragen Sie beim Arrangement die **Erwartete Besetzung** ein oder übernehmen
   Sie eine **Besetzungsvorlage**. Kennzeichnen Sie Stimmen als erforderlich oder
   optional. Eine Vorlage wird kopiert; spätere Vorlagenänderungen verändern die
   bestehende Erwartungsliste nicht. Ein Ersetzen muss ausdrücklich bestätigt werden.

Ohne festgelegte Erwartungsliste lautet der Status **Unbekannt**. Auch eine
bewusst festgelegte leere Liste ist möglich. Die erwartete Besetzung sagt noch
nichts darüber aus, ob geprüfte Notendateien vorhanden sind.

Mit **Suchen** finden Sie auch Teilnamen und Aliasse. **Aktive**, **Inaktive** und
**Alle** bestimmen die sichtbaren Datensätze. Auf kleinen Bildschirmen können
Sie die Register und Tabellen seitlich verschieben.

Verwendete Datensätze können nicht einfach gelöscht werden. Deaktivieren Sie
sie über **Bearbeiten**, damit alte Zuordnungen erhalten bleiben. Stimmen oder
Varianten aktiver Mitglieder bleiben geschützt; ändern Sie zuerst deren
Stammstimme oder deaktivieren Sie das betreffende Mitglied.

Wurde ein Datensatz zwischenzeitlich geändert, laden Sie die Seite neu, prüfen
Sie den aktuellen Stand und wiederholen Sie Ihre Änderung bewusst.
