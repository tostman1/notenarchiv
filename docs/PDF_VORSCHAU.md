# Sichere PDF-Vorschau

Die Vorschau zeigt die tatsächliche CLEAN-Version. „Ungeprüfte Version“ bedeutet
nicht, dass die Noten bereits zur Ausgabe freigegeben sind.

- Mit **Vorherige Seite**, **Nächste Seite** oder **Seite** wechseln Sie die Seite.
- Unter **Zoom** wählen Sie 50 bis 200 Prozent. Große Seiten können innerhalb
  der Vorschau gescrollt werden. Die Steuerung ist auch per Tastatur erreichbar.
- Das Öffnen oder Betrachten der Vorschau bestätigt keine Inspektion und gibt
  keine Noten frei. Die ausdrückliche Prüfung wird im späteren Prüfablauf erfasst.
- PDF-interne Links, Skripte und interaktive Formulare werden nicht ausgeführt.
- Ist die Vorschau nicht verfügbar, laden Sie die Seite erneut. Prüfen Sie bei
  anhaltenden Problemen den Dateistatus; fehlende oder beschädigte Dateien
  werden nicht stillschweigend durch eine andere Version ersetzt.

Die Vorschau benötigt JavaScript und eine Anmeldung. Sie lädt keine Inhalte
von externen Diensten. Bibliothek und Prüfwarteschlange werden in ihren eigenen
Arbeitspaketen mit dieser Vorschau verbunden.
