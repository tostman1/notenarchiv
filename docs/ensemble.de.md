# Ensemble-Rollen ausdrücklich zuordnen

Im Projekt **Ensemble-Rollen und Zuordnungen** öffnen. Eine musikalische Rolle
beschreibt die Aufgabe im Ensemble, nicht eine Instrumenten- oder Stimmennummer.
Beispiel: Rolle 3 kann mit einer Posaunenstimme im Bassschlüssel und einer passenden
Tenorhornstimme in anderer Stimmung/Notation besetzt werden. Keine automatische
Transposition und keine automatische Zuordnung anhand derselben Nummer.

1. **Rolle hinzufügen**: Kürzel und musikalische Bezeichnung speichern.
2. Bei ausgewählten Teilnehmenden die **Musikalische Rolle** wählen und speichern.
   Eine leere Rolle bedeutet ausdrücklich: gespeicherte Projektstimme verwenden.
3. **Mapping hinzufügen**: Rolle, exakte Instrumentenvariante und passende spielbare
   Stimme wählen. Position leer lassen für die Projektvorgabe; für eine Ausnahme
   ein konkretes Stück wählen. Reserven sind nicht zuordenbar.
4. **Mapping-Vorschau** zeigt pro Person die aktuelle Rollen-Zuordnung. Eine
   Positionsausnahme hat Vorrang vor der Projektvorgabe. Fehlende oder ungültige
   Zuordnungen werden deutlich angezeigt, nicht still durch Stammstimmen ersetzt.
5. **Mapping ausdrücklich zurücksetzen** entfernt nur die aktive Vorgabe, nicht
   die Historie. Eine Ausnahme fällt danach ausdrücklich auf die Projektvorgabe
   zurück. Zum Wiederverwenden das erhaltene Mapping bewusst bearbeiten.

Referenzierte Rollen können erst deaktiviert werden, nachdem die Zuordnung für
ausgewählte Personen ausdrücklich gelöst wurde. Namen, gespeicherte Projektstimmen,
persönliche Stück-Overrides und gemeinsame Stückliste bleiben unverändert.
Bei parallelen Änderungen neu laden und bewusst erneut speichern.

Die Vorschau löst noch keine konkrete Ausgabe auf; diese Aufgabe übernimmt WP-32.
Rollen-Mapping ist keine Freigabe von Noten. Private NAS-Abnahme bleibt separat.
